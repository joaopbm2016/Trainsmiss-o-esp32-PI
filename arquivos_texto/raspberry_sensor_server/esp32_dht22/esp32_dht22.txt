EXPLICACAO LINHA POR LINHA: esp32_dht22.ino

Este programa roda no ESP32 conectado ao DHT22. Ele le temperatura e umidade,
adiciona um horario e envia cada leitura ao servidor HTTP do Raspberry Pi. Sua
importancia e fazer a ponte entre o sensor fisico e o banco de dados.

As referencias usam os numeros de linha do sketch original. Todas as linhas
com codigo estao explicadas. Linhas em branco apenas organizam o codigo.

1: Importa recursos basicos da plataforma Arduino.
2: Importa funcoes de Wi-Fi do ESP32 para conectar a rede.
3: Importa o cliente HTTP usado para enviar requisicoes ao Raspberry.
4: Importa o suporte ao sensor DHT.
5: Importa funcoes de horario e data.
6: Linha em branco para separar bibliotecas das configuracoes.
7: Define o nome da rede Wi-Fi; substitua SEU_WIFI pelo SSID real.
8: Define a senha da rede; substitua SUA_SENHA antes de compilar.
9: Define o endereco IP do Raspberry Pi; deve corresponder a rede usada.
10: Define a porta HTTP do servidor; 8080 e o padrao do servidor Python.
11: Define um identificador unico para este dispositivo; outro ESP32 deve usar
    outro identificador para distinguir suas leituras.
12: Define a chave opcional da API; se o servidor exigir SENSOR_API_KEY, use
    aqui o mesmo valor.
13: Linha em branco de separacao.
14: Define GPIO 4 como pino de dados do DHT22.
15: Informa a biblioteca que o modelo do sensor e DHT22.
16: Linha em branco de separacao.

18: Define o intervalo de envio em 30.000 milissegundos, ou 30 segundos.
