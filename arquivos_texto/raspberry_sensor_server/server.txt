EXPLICACAO LINHA POR LINHA: raspberry_sensor_server/server.py

Este arquivo inicia um servidor HTTP no Raspberry Pi, recebe leituras de
temperatura e umidade dos ESP32, guarda os dados em SQLite e oferece uma pagina
web para consulta. A importancia dele e centralizar e disponibilizar as
medicoes.

As referencias abaixo usam os numeros de linha do arquivo Python original.
Todas as linhas com codigo estao explicadas. Linhas em branco servem apenas
para organizar o codigo e nao alteram sua execucao.
